# SkyHawk Recovery Project (SHRP) for Redmi Note 8 Pro (`begonia`)

Automated **GitHub Actions** CI builder and complete device tree for **SkyHawk Recovery Project (SHRP 12.1)** on **Xiaomi Redmi Note 8 Pro** (`begonia` / `begoniain`).

## Features
- **Material 2.0 Card UI**: Visual cards, animated transitions, and battery/thermal sensors dashboard.
- **Hardware Tools**: Built-in Camera2API toggles and CPU governor controls.
- **Unified Partition Support**: Mounts both legacy physical partitions and retrofitted dynamic partitions (`super`).

## Build via GitHub Actions
```bash
gh workflow run "SHRP Recovery Build (begonia)"
```
Or trigger manually from the **Actions** tab on GitHub.
